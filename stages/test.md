# `<test>` 全局验收

## 职责

维护并执行 `test/acceptance/**` 中跨组件、从真实系统入口验证用户可观察结果的验收测试。
组件内部测试使用 `<test 组件>`。

## 权限

| 路径 | 创建 | 读取 | 修改 | 删除 |
|---|---|---|---|---|
| `**` | 禁止 | 禁止 | 禁止 | 禁止 |
| `docs/**` | 禁止 | 允许 | 禁止 | 禁止 |
| `apps/**` | 禁止 | 允许 | 禁止 | 禁止 |
| `test/acceptance/**` | 允许 | 允许 | 允许 | 允许 |

## 执行

1. 从相关 `REQ-*` 读取 AC、TC，从参与组件 README 解析应用目录并读取必要设计、入口和测试。
2. 建立 `TC → AC → 系统入口 → 可观察结果` 映射；预期缺失或冲突时返回对应 `<doc 组件>`。
3. 只实现用户要求的跨组件场景及必要支持代码；`opt` 时只修改唯一目标文件。
4. 在隔离的非生产环境先运行修改场景，再运行受影响验收测试；不默认生成报告或覆盖率。

## 完成检查

- 修改只在 `test/acceptance/**`，没有复制组件测试、业务规则或契约模型。
- 测试使用真实 TC，经过真实入口并断言跨组件状态或用户结果。
- 结果如实区分通过、失败、跳过和未执行。
